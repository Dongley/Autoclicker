# 탭 오토클리커

갤럭시 탭용 자동 클릭 앱. 화면 좌표를 선택하고 **10초 동안 1초 간격으로 클릭 → 1초 길게 누르기**를 무한 반복합니다.

- Android 8.0 이상
- 접근성 서비스를 통한 터치 제스처
- 화면 위의 이동 가능한 위치/시작/정지/숨김 버튼
- 인터넷 연결 및 루트 권한 불필요

## APK 다운로드

GitHub의 **Actions → Build installable APK**에서 빌드가 완료되면 실행을 열고 **Artifacts → TabAutoClicker-APK**를 내려받으세요. 압축을 풀면 `app-debug.apk`가 있습니다.

설치 후 앱에서 접근성 서비스를 켜고, 화면의 `위치` 버튼으로 자동 클릭 위치를 지정한 뒤 `시작`을 누르세요.

일부 앱은 자동 입력을 제한할 수 있습니다. 화면 회전 후에는 위치를 다시 지정하세요.
